## ⚖️ 1. INTRODUCTION AND DUAL CONCEPTUAL FRAMEWORK

In the Republic of Peru, software protection is regulated in a **dual** manner. This means that the **expression of the code** is protected through Copyright, and the **functional technical effect** of the algorithms is protected exceptionally through the Industrial Property Regime (Invention Patents).

```
                                  SOFTWARE SYSTEM
                                [SportMatch Connect]
                                         |
                  +----------------------+----------------------+
                  |                                             |
        Route 1: Copyright                            Route 2: Industrial Property
       (Code Expression)                              (System Technical Effect)
                  |                                             |
       [Copyright Directorate]                  [Inventions & New Tech. Directorate]
                  |                                             |
      Logical Support Registration                     Invention Patent (CII)
   (Source Code, Binaries & Manuals)             (Matchmaking & Edge Moderation)
```

This manual provides detailed guidelines of global professor level to guide researchers in the preparation of registration files before the **National Institute for the Defense of Competition and Intellectual Property Protection (INDECOPI)**.

**2. Objective of the Software** (recommended length: 2-3 pages)
Write clearly and concisely the problem that SportMatch Connect solves, including:

- **Identified problem:** The logistical difficulty faced by amateur and semi-professional athletes in Peru to find opponents or playmates with a similar competitive level, in nearby geographic locations, and at compatible times. Existing solutions (informal leagues, WhatsApp groups, generic meeting applications) lack intelligent matching systems, content moderation, and integrated sports facility booking.
- **Proposed solution:** SportMatch Connect solves this problem through a comprehensive digital ecosystem that combines:
  - Geospatial matching algorithm (Haversine) that calculates distances between users in real time and suggests meetings within a configurable radius (1-50 km).
  - Dynamic rating system (Elo with variable K between 16 and 48) that adjusts each user's score after each match, enabling fair pairings based on demonstrated competitive level.
  - Stable matching algorithm (Gale-Shapley) that maximizes overall participant satisfaction in tournaments and leagues.
  - Edge content moderation (Edge AI) with TensorFlow.js NSFWJS, which analyzes images on the client device before uploading them to the server, reducing latency and bandwidth consumption.
  - Generative AI conversational assistant (Sporty AI) based on Google Vertex AI Gemini 2.5 Flash for personalized queries.
  - Sports facility booking system with Stripe, including fractional payment with FitCoins and payment splitting among participants.
- **Target users:** Amateur athletes (18-45 years), sports complex administrators, personal trainers, and semi-professional clubs.

**4. System Flowcharts** (recommended length: 5-10 pages)
Include flow diagrams that visually describe the critical processes:

- **Authentication and Registration Flow:**
  1. User enters email and password → 2. Supabase Auth validates credentials → 3. JWT session is created/retrieved → 4. NestJS middleware verifies token → 5. Database queries profile → 6. Personalized dashboard is rendered.

- **Geospatial Matchmaking Flow:**
  1. User enables geolocation in browser → 2. GPS coordinates (lat, lng) are obtained → 3. Haversine algorithm calculates distances to all open matches → 4. Elo algorithm filters by competitive level (±200 point tolerance) → 5. Gale-Shapley assigns stable pairings → 6. Best matches are presented in composite score order.

- **Stripe Booking and Payment Flow:**
  1. User selects complex on Leaflet map → 2. Selects date and time → 3. System verifies availability → 4. Payment split among participants is calculated → 5. Stripe Payment Intent is created on backend → 6. Each participant confirms their share → 7. Stripe confirms full payment → 8. Booking is created in Supabase with RLS → 9. Push notification to all participants.

- **Edge Moderation Flow (Edge AI):**
  1. User selects image to upload → 2. TensorFlow.js loads NSFWJS model in browser → 3. Image is analyzed locally (classification: normal / NSFW) → 4. If NSFW (>0.8 probability), it is blocked and a warning is shown → 5. If safe, it is compressed and uploaded to Supabase Storage → 6. User trust_score is updated.

- **Conversational Query Flow (Sporty AI):**
  1. User types or dictates question by voice → 2. Text is sent to NestJS endpoint → 3. Vertex AI Gemini 2.5 Flash generates embedding → 4. System queries relevant context (nutrition, matches, complexes) → 5. Gemini generates response with RAG → 6. Response is streamed to frontend → 7. Displayed in chat widget.

## 🔬 3. PATENT REGISTRATION GUIDE (COMPUTER-IMPLEMENTED INVENTIONS - CII)

Registration before the **Directorate of Inventions and New Technologies (DIN)** is a highly demanding process focused on patenting a system or method that produces a **novel technical effect in the physical world**.

### ⚙️ 3.1. Global Patentability Requirements
To obtain an invention patent, SportMatch Connect must pass a substantive examination of three requirements:
1.  **Global Novelty:** That no identical system exists globally published in patents, scientific articles, or commercial platforms before the filing date.
2.  **Inventive Step:** That the solution is not obvious to an average systems engineer or a person with ordinary technical skills in the field.
3.  **Industrial Applicability:** That the system can be manufactured, reproduced, or used constantly in any type of industry or economic sector (fulfilled with its commercial B2B/B2C deployment).

### 💡 3.2. What is a Computer-Implemented Invention (CII)?
According to the DIN guidelines of INDECOPI, a computer program by itself is not patentable. However, when the software is part of a **method or system that integrates with hardware to perform technical transformations or interact with physical variables**, it qualifies as a CII.
*   *Technical Effect in SportMatch Connect:* The invention claims the physical interaction of the user's device (GPS coordinates of latitude and longitude processed by Haversine and Elo algorithms) integrated with a secure transaction system from Stripe and edge image pre-moderation with TensorFlow.js. This optimizes compute resource usage and reduces latency in physical telecommunication networks.

### 📝 3.3. File Structure and Patent Fees
The patent file must be written with extreme scientific and legal rigor, structured into:
1.  **Descriptive Memory (Technical Description):** Detailed description of the state of the art, deficiencies of current systems, detailed description of the invention, and reference to figures.
2.  **Claims Set:** The legal clauses defining the boundary of what the inventor claims. They must be drafted as "system", "method", or "computer storage medium" (not as "code").
3.  **Invention Abstract:** Technical synthesis of maximum 150 words.
4.  **Figures/Drawings:** C4 Container layouts, sequence flowcharts, and database schemas indexed spatially.
5.  **Filing and Examination Fees (DIN):**
    *   *Application Filing Fee:* Code **202000627** (Amount: **S/ 396.00 PEN**). Source: TUPA INDECOPI approved by Supreme Decree N° 088-2025-PCM (June 30, 2025) and official portal patenta.pe. Represents a 45% reduction from the previous fee of S/ 720.00.

## ❓ 5. FREQUENTLY ASKED QUESTIONS (FAQ) ABOUT THE PROCESS

### 5.1. About Copyright Registration

**Q: Is it mandatory to register the software with INDECOPI to have copyright?**
A: No. According to Article 3 of DL 822, copyright protection arises with the creation of the work itself, without the need for registration. However, registration with INDECOPI provides **certain date** and **legal presumption of authorship**, which is crucial in case of plagiarism or legal dispute.

**Q: Can I register the software under the entire team's name?**
A: Yes. In the F-DDA-02 form, all co-authors (Flores, Andrade, Espinoza, Gastelu, Salvatierra) are declared. If the economic rights are assigned to USIL, the assignment letter must be attached. Moral rights (attribution and integrity) are inalienable and always belong to the original authors.

**Q: What protection do I get exactly with registration?**
A: The registration certificate certifies that on a given date (filing date), the applicant declared being the author of that source code. In case of dispute, it reverses the burden of proof: the claimant must prove that the registration is false.

**Q: How much does it cost and how do I pay?**
A: S/ 390.50 (code 203000707) through Pagalo.pe or Banco de la Nación. See section 2.2.1 for the detailed payment procedure.

**Q: How long does the process take?**
A: Approximately 15-20 business days without observations, and 30-40 business days with observations. See section 2.6 for more details.

**Q: Does registration in Peru protect me in other countries?**
A: Registration with INDECOPI is valid in Peruvian territory. For international protection, registration can be requested at **WIPO** through the Berne Convention (of which Peru has been a member since 1988). CAN Decision 351 also extends protection to Bolivia, Colombia, and Ecuador.

### 5.2. About the Invention Patent

**Q: Is SportMatch Connect really patentable?**
A: Software "as such" is not patentable (Art. 15.e Decision 486). However, SportMatch Connect qualifies as a **Computer-Implemented Invention (CII)** because it produces a novel technical effect in the physical world: GPS coordinate processing, edge visual moderation that reduces network latency, and atomic financial transactions.

**Q: How much does the entire patent process cost?**
A: The filing fee is S/ 396.00 (code 202000627) and the substantive examination fee is S/ 324.00 (code 202000628), totaling S/ 720.00. Added to this is the state of the art search if requested from INDECOPI, and fees for a specialized industrial property attorney.

**Q: How long does patent protection last?**
A: The invention patent lasts **20 years** from the filing date of the application (Art. 33 TRIPS Agreement and Art. 69 Decision 486), subject to payment of annual maintenance fees.

**Q: What happens if I disclose my project before patenting?**
A: Public disclosure (social media posts, fair presentations, public GitHub publication) before filing the application **destroys novelty** and makes the patent impossible to obtain. It is recommended to keep the repository private until after filing the application.

**Q: Can I patent after registering copyright?**
A: Yes, as long as there has been no public disclosure of the novel technical effect. It is recommended to first register the copyright (S/ 390.50) and then file the patent application (S/ 720.00), in that order.

### 5.3. About Legal and Administrative Aspects

**Q: Do I need a lawyer to process the application?**
A: Not required for copyright registration if the application is well prepared. For the patent, it is recommended to have an attorney specialized in industrial property due to the technical complexity of the claims.

**Q: What happens if my application receives observations?**
A: INDECOPI will notify the observations through the Virtual Filing Office. You have **10 business days** to remedy them. If you do not remedy them within the deadline, the application is considered abandoned.

**Q: Is the deposited source code public?**
A: No. The source code deposit is **confidential** and is only used for verification purposes in case of legal disputes. INDECOPI does not publish the deposited source code.

**Q: What validity does the INDECOPI digital certificate have?**
A: The certificate issued by the Virtual Filing Office has the same legal validity as a physical certificate, being digitally signed by the competent authority. The electronic verification code allows online authentication of its authenticity.

**Q: Can I process the application from outside Lima?**
A: Yes. The entire process can be carried out 100% virtually through the INDECOPI Virtual Filing Office. It is not necessary to travel to Lima for any step of the process.
